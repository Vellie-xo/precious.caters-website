# Precious Caters 🍽️✨

Precious Caters is a modern, responsive web application built for a community-centric Southern African catering service. The platform allows clients to explore menu offerings, interactively rate service options, and submit catering inquiries directly to the owner.

## 🚀 Features

- **Responsive Layout:** Dynamic, card-based service sections that adapt fluidly across mobile, tablet, and desktop screens.
- **Scroll Animations:** Smooth scroll-triggered reveal effects powered by **ScrollReveal.js** as users navigate the page.
- **Interactive Star Rating System:** Dynamic rating logic built with JavaScript that stores user feedback in `localStorage` for persistent interaction.
- **Direct Form Integration:** Integrated contact form using **Formspree** to route event inquiries straight to the owner's email.
- **Instant Communication:** Floating WhatsApp web button using Boxicons for quick client-to-business messaging.
- **Modern UI/UX:** Clean typography, hover micro-interactions, and accessibility-focused design.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Animations:** ScrollReveal.js
- **Iconography:** Boxicons CDN
- **Form Handling:** Formspree API
- **Storage:** Browser `localStorage` API
